CiakTV — Privacy Policy

Last updated: 7 November 2026

CiakTV is a local media player for Fire TV. It does not require an account, does not use analytics or advertising SDKs, and does not send your data to the developer or to third parties.

Data stored on the device

  • Playlists you add: name, M3U URL and optional EPG URL.
  • Cached channel data, programme guide data and channel logos fetched from the URLs you provide.
  • Favorites, recent channels, blocked channels and reminders.
  • Settings: language, User-Agent, default EPG, buffer size, picture format and PIN hash.
  • Local backup file created only when you use “Export backup”.

This data stays in the app's private storage (and the app's external files directory for the backup file) and is not uploaded to the developer. It can be removed by deleting the playlist, clearing the app data, or uninstalling the app.

Network

  • CiakTV downloads the M3U playlist, XMLTV guide and channel logos from the URLs you enter. Those servers are chosen by you; their privacy policies apply.
  • If you leave the EPG field empty, CiakTV may use a public EPG URL selected for the app language (for example epgshare01.online). You can replace it in Settings.
  • The QR setup page is served by a temporary HTTP server on the TV, only on the local network, and stops when the dialog is closed.
  • No CiakTV account, cloud service or telemetry endpoint is used.

Permissions

  • Internet and network state: playlists, EPG, logos and local QR setup.
  • Notifications: optional program reminders.
  • Receive boot completed: reschedule reminders and the daily playlist sync.
  • No contacts, camera, microphone, location or broad storage access.

Children / content

CiakTV does not provide, host or include channels, playlists or media. The user is responsible for the sources they add and for the rights to them. DRM removal and illegal content are not supported.
